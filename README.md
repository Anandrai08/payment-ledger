# payment-ledger

A production-inspired Payment Ledger System built with Spring Boot that demonstrates how modern payment platforms process transactions using double-entry accounting, idempotency, and transaction orchestration.

🚀 Features
Wallet management
Money transfers
Double-entry ledger
Deposits & refunds
Idempotent transactions
Audit logging
Flyway database migrations
REST APIs
JUnit & Mockito tests
Docker support
🛠️ Tech Stack
Java 17
Spring Boot 3
Spring Data JPA
MySQL
Flyway
JUnit 5
Mockito
Testcontainers
Docker
▶️ Run Locally
git clone https://github.com/Anandrai08/payment-ledger.git
cd payment-ledger

mvn clean install
mvn spring-boot:run
🧪 Run Tests
mvn test
